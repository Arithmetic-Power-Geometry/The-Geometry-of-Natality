## Mathematical advance tested
Define enabling creation sets X⊆E by existence of an admissible goal-reaching path within budget B, and minimal enabling sets W. Under fixed semantics where disabling creation capabilities only removes actions, D blocks every feasible goal-reaching plan iff D intersects every W. Minimal blockers are minimal hitting sets of W. Proof: E\D enables the goal iff it contains some W, so D blocks iff no W is disjoint. **This is classical hypergraph transversal duality applied to the creation-capability model; not a genuinely new theorem.**
