# GoN V15 Q1 assessment
Verdict: NO, Q1-level contribution has not been established.
V15 proves a clean, small counterexample separating classical degree and adjacency-spectrum summaries from rooted reachability. This is useful as a negative-control theorem and as book pedagogy.
However rooted reachability is directly computed by BFS, so this is NOT evidence that GoN outperforms standard graph methods. The phenomenon is elementary; priority and broader related literature need checking.
Required next: a decision task with constrained creation actions, an independently defensible theorem beyond reachability folklore, and fair baseline comparisons against SCC, exact enumeration, ILP, and graph rewriting.
